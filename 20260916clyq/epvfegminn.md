# 产检最常做的尿常规，90%的孕妈都看不懂！今天一次讲明白

> 更新时间：2026-09-16 (UTC+8)

每次产检拿到尿常规报告单，看着上面的（+）（-）或↑↓箭头
，是不是一脸懵？

“尿蛋白有加号，是不是肾脏出问题了？”“尿糖阳性，难道我得了糖尿病？”

别慌，这份小小的尿常规报告，其实是孕期健康的“晴雨表”。今天我们就来手把手教你看懂它。

**0****1****两大“侦察兵”，各显神通**

尿常规报告，主要由两位“侦察兵”共同完成，它们互相配合，才能做出最准确的判断。

**快速筛查员：尿干化学（试纸条法）**
**工作方式：**像pH试纸一样，通过试纸的颜色变化来快速判断。

**侦察目标：**尿蛋白、尿糖、酮体、白细胞、潜血等。它的特点是快，能第一时间发现可疑线索。

**精准显微镜：尿沉渣分析**
**工作方式：**将尿液离心后，在显微镜下进行“实地勘察”。

**侦察目标：**红细胞、白细胞、管型、结晶、上皮细胞等有形物质。它的特点是准，能看清到底是什么“家伙”在捣乱。

**0****2****报告单上的“红绿灯”信号解读**

当看到报告单上的（+）、（-）或↑↓箭头时，可以这样初步理解：

**（-）阴性 / 在参考范围内：**绿灯通行！这项指标正常，值得开心。

**（+）阳性 / ↑ 升高：**黄灯提醒！这项指标异常，需要引起注意，并咨询医生。

**（++）或更高 / ↑↑ 显著升高：**红灯警报！这项指标明显异常，必须立即交由医生评估处理。

**0****3****孕期重点监控的“三大主角”**

在孕期，医生会特别关注以下三个指标，它们是母婴安全的“守护神”：

**尿蛋白（PRO）：肾脏的“警报器”**
正常应是阴性(-)，如果出现“+”号，是需要高度警惕的信号！

它可能是**妊娠期高血压疾病**或**子痫前期**的早期表现，说明肾脏的“滤网”可能受损了。医生会结合你的血压、水肿等情况综合判断。

**尿糖（GLU）：血糖的“风向标”**
正常应是阴性（-），如果出现“+”号，别立刻断定是糖尿病！

孕期因肾脏“门槛”（肾糖阈）降低，容易出现**生理性尿糖**。但它也是一个重要提醒，提示你需要关注血糖，医生可能会建议你做糖耐量检查（OGTT）来明确诊断。

**白细胞（LEU）尿沉渣白细胞：感染的“侦察兵”**
正常应是阴性(-)或数量在正常范围，如果双双明显升高伴或不伴亚硝酸盐阳性，通常是尿路感染的明确信号。

孕期由于子宫压迫，极易发生**尿路感染**，需要及时治疗，以免影响妈妈和宝宝的健康。

**0****4****其他常见项目的“真心话”**

**✦潜血（BLD）& 尿沉渣红细胞：**提示泌尿系统可能有出血，原因多样，需医生排查。

**✦酮体（KET）：**阳性可能意味着身体在消耗脂肪，常见于孕吐严重、进食不足、晨起空腹留尿的孕妈；糖尿病血糖控制欠佳也常见，大多与尿糖阳性伴随。

**✦结晶：**增多是在提醒你“该多喝水啦！” 以防形成结石。

**✦上皮细胞（尤其是鳞状上皮细胞）增多：**这通常是 “虚惊一场” ！十有八九是留尿时被白带稍微污染了，不代表疾病。下次记得留取更标准的 “中段尿” 就好。

**✦出现“管型”，特别是“颗粒管型”等：**这是一个需要特别关注的信号，可能提示肾脏的滤过功能受到了影响，常与妊娠期高血压或子痫前期相关。

**✦尿比重：**反映尿液“浓度”，喝水多少会影响它。

**✦酸碱度（pH）：**正常尿液就是弱酸性的，小幅波动没关系。

**✦尿胆原、胆红素：**主要和肝脏、胆囊功能有关，通常孕期是正常的。

**产检前尿液样本这样留，更准确！**

尿常规检查虽小，却是孕期监测的重要环节，它帮助医生了解孕妈的肾功能、尿糖、尿蛋白及感染情况。

**🕒留取时间：**建议餐后1小时左右留尿，此时尿液成分更稳定，避免空腹尿或晨尿带来误差。若医生有特别要求，请以医嘱为准。

**🧴留取步骤：**

1.洗净双手，使用干净的留尿杯（带盖更好）。

2.清洁外阴：从前往后轻擦。

3.开始排尿，前段尿不要接；中段尿接入留尿杯约半杯即可。

4.盖紧瓶盖，30–60 分钟内送检。

5.若近期用药或感染，请告知医生。

⚠️注意事项：避免晨尿；留尿前 2 小时不宜吃太甜或高蛋白食物；如当天还有B超或血糖试验，和医生确认留尿顺序。

各位孕妈们，请理性看报告，不要看到一个箭头就恐慌。很多指标需要结合临床综合判断。

有任何疑问或身体不适（如尿频、尿痛、腰酸等），一定要及时告诉你的产检医生。

这份小小的尿常规报告，是孕期的健康防线，能早期、无声地揭示许多潜在问题。请务必重视每一次检查，确保你和宝宝能平稳、顺利地度过整个孕期。
